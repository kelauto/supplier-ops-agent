# Supplier Ops Agent

An e-commerce operations agent. It reads a supplier inbox and an order book, then
produces a triaged action list and an operational report — so nothing slips
because a human didn't get to the inbox that day.

## What it does

- **Classifies every supplier email** by intent — `quote`, `delay`, `invoice`,
  `shipping`, `complaint` — with a confidence score
- **Flags overdue orders** against their promised ship date and totals the value at risk
- **Drafts the follow-up reply** per supplier, ready to send
- **Writes an ops report** (HTML) and an **action list** (CSV)

## Quickstart

No dependencies. Python 3.8+, standard library only.

```bash
python3 agent.py --seed-demo   # writes a sample inbox/ and orders.csv
python3 agent.py               # run the triage
```

Example run:

```
→ triaging 5 emails  (rule engine)
✓ 5 emails triaged: complaint(H), shipping(H), delay(H), quote(H), invoice(M)
✓ 3 overdue orders · $16,872 at risk
✓ wrote actions.csv
✓ wrote ops_report.html
```

## How it works

```
inbox/*.txt ──┐
              ├─► classify (intent + urgency) ──┐
orders.csv ───┘                                 ├─► prioritise ─► actions.csv
              └─► overdue detection ────────────┘              └─► ops_report.html
```

Priority is not sentiment — it's arithmetic:

| Priority | Trigger |
|---|---|
| HIGH | flagged urgent, complaint, or >3 days late |
| MEDIUM | delay, quote, or any days late |
| LOW | everything else |

## A note on the AI step

Classification runs through a deterministic rule engine by default, so the tool
works with **zero setup and no API key**.

An LLM path is available and deliberately pluggable:

```bash
export OPENAI_API_KEY=sk-...
python3 agent.py --use-llm
```

If the key is missing or the call fails, it **falls back to the rule engine and
says so** on stdout. It never presents a stub call as real inference — a
classification pipeline that lies about its own confidence is worse than one that
admits it doesn't have any.

## Files

| File | Purpose |
|---|---|
| `agent.py` | Everything — classification, tracking, drafting, reporting |
| `inbox/` | Sample supplier emails (generated by `--seed-demo`) |
| `orders.csv` | Sample order book |
| `actions.csv` | Output: prioritised action list |
| `ops_report.html` | Output: client-facing report |

## Extending it

- Add an intent by appending to `RULES` and adding a draft to `DRAFTS`
- Swap the CSV order book for a live API call in `load_orders()`
- Wire `write_actions()` to Slack/Sheets for real-time ops
